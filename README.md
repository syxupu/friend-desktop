# Friend 学习桌宠

Windows 10 / 11 x64 的本机桌宠原型。桌宠上方显示流式回复，下方直接输入；拖动狐狸移动位置，从托盘打开聊天，聊天窗口内的 ⚙ 设置按钮切换大小窗。对话由随软件运行的 **SillyTavern 1.19.0** 处理角色卡、世界书和上下文，用户选择的 OpenAI 兼容接口提供生成，MiMo 提供语音。

**当前源码版本为 0.5.2，不包含角色卡、API 密钥、聊天记录、个人运行数据或已有安装包。** 使用前请自行准备角色卡和配置自己的密钥，见下方“开发”。现有本机打包目录含私人角色卡，不作为公开发行包上传。文档中提到的本机验证 JSON、截图及评审页面未纳入公开仓库。

在另一台电脑继续开发，请先阅读 [开发交接](docs/HANDOFF.md) 和根目录 [AGENTS.md](AGENTS.md)，其中包含环境准备、实现边界、已确认规则、代码导航、验证限制及待办建议。

## 运行

打开 `release/0.5.2/win-unpacked/Friend 桌宠.exe`。保留整个 `win-unpacked` 文件夹，不能只复制 exe。程序包含 Node 和酒馆运行依赖，首次启动需要编译酒馆前端，请稍候。旧版输出保留在原目录，新旧版本不要同时运行。

桌宠新聊天和学习新段均从空白开始，不加载角色卡开场白。切换角色、重新打开会话和生成前，会将可识别的首条卡片开场消息经酒馆确认移除，并在该聊天文件的元数据 `friend_greeting_backup` 中保留原消息；角色卡开场字段不改动，已有模型回复保留。结束本段进入休息时，按权威学习状态自动生成一次休息回复；开始、暂停、继续和结束整个任务目前仅产生本地通知，随后等待用户输入，没有定时主动闲聊。

删除当前气泡对应的最新回复后，气泡保持空白，不自动回退显示前一轮；删除中间第 i 轮回复（i < n）时，第 n 轮回复保持显示。点击狐狸、刷新配置和重启不会重新显示被删除回复之前的旧内容；新回复或新提示会正常显示。此状态按当前会话保存，不改变聊天记录、计时或轮数。

### 删除记录与角色书条目（0.5.0）

“学习与聊天记录”的每次任务/自由聊天和每个学习段旁均有删除按钮。删除整次记录会删除其中全部段；删除单段保留其他段，最后一段删除后移除空任务。操作前在界面确认。当前学习任务不能整次删除，当前学习/休息段和正在使用的会话不能删除；结束任务或新开聊天后可处理相应记录。删除历史不会切换当前酒馆会话。

历史聊天先备份到本机 `chat-deletion-backups/`，再通过酒馆接口确认删除，最后原子提交归档索引。中途失败会恢复仍被索引引用的缺失聊天；意外关闭后会在启动时恢复未提交删除。备份不显示在聊天列表，可供人工恢复；本功能不是清除全部备份的隐私擦除功能。

“角色书与高级内容”列出内嵌角色书及关联世界书的条目，相同的配对条目合并展示，每条可删除。请先保存角色/偏好草稿并结束当前学习任务。删除会备份原 PNG，并校验版本；关联世界书条目在当前角色的独立副本中删除后重新关联，原共享世界书及其他角色保持原状。其余人设、头像、未知字段与条目保留；已有聊天中的内容不会被改写。

隔离验证脚本为 `node scripts/deletion-integration.mjs`，`--packaged` 验证成品；使用真实酒馆与本机模拟接口。

### 桌宠对话与 API（0.4.0）

普通启动默认只显示桌宠。下方输入框支持 Enter 发送、Shift+Enter 换行和中文输入法；上方气泡实时显示最新回复，可滚动、收起，下一条回复自动展开。生成时点击“停止”终止真实生成，语音播放时可停止播报。桌宠不显示状态/工具栏；从托盘打开聊天查看完整聊天与学习控制，或右键狐狸打开设置。点击狐狸可聚焦输入并重新展开最近回复。聊天窗口的顶栏由 ⚙ 设置按钮负责大小窗切换。

在“陪伴设置 → 桌宠外观”调整 50%–200% 大小，保存后生效。输入框和回复字号保持可读；气泡与输入框的宽度只由桌宠大小设置决定（100% 时外层宽度 324 像素），拖动、两侧空余空间和长回复不会改变宽度。过长文字自动换行、回复内容可滚动；拖动狐狸移动整个桌宠。 宽度与拖动界面回归：`node scripts/pet-layout-integration.mjs`（模拟桥接）；成品的真实窗口拖动及模拟 API 回复检查：`node scripts/pet-api-integration.mjs --packaged`。

“对话 API”提供 DeepSeek、OpenAI、硅基流动、阿里云百炼国内、Moonshot/Kimi 国内和自定义 OpenAI 兼容接口。选择供应商后填写 API 基础地址和该服务的密钥，点击“获取模型列表”，选择模型后保存；不支持 `/models` 的服务可以手动填写模型 ID。当前保存一组对话配置，供应商选项为地址预设，不是多个账号配置库。仅支持 Chat Completions 兼容接口，未增加 Anthropic 原生协议或 Coding Plan 专用认证。

获取列表不会保存表单，也不会发起对话生成。已保存密钥只允许用于原基础地址；改地址需重新填密钥或明确清除，避免旧密钥被带往新服务。列表失效、鉴权失败、网络失败时保留手动模型入口。密钥继续由主进程加密存储，界面只收到是否已保存。

布局参考酒馆原生供应商/地址/密钥/模型流程及 [CC Switch 供应商配置](https://github.com/farion1231/cc-switch/blob/main/src/config/codexProviderPresets.ts)；模型列表采用兼容的 `GET /models`，例如 [DeepSeek 文档](https://api-docs.deepseek.com/api/list-models/) 和 [硅基流动文档](https://api-docs.siliconflow.cn/docs/api/models-get)。隔离验证脚本为 `node scripts/pet-api-integration.mjs`，加 `--packaged` 验证成品，使用真实酒馆与本机模拟接口；不代表真实供应商或模型效果验收。

### 角色管理（0.3.0）

学习中心左侧的“角色管理”支持快捷新建与快速编辑：名称、完整人设描述、性格与说话风格、关系与日常场景、开场白和可选对话示例。已有卡的未知字段、提示词和角色书保留，保存前自动把原 PNG 备份到本机用户数据的 `character-backups/`。编辑版本过期时拒绝覆盖，草稿仍留在界面。另存为桌宠版创建新的角色文件，保留头像、原卡高级内容和世界书关联；关联的外部世界书仍可能共享，如需独立改世界书，请在酒馆另存。

“陪伴偏好”单独保存到 `companions.json`，按角色区分回复篇幅、动作旁白、追问偏好，以及学习/暂停、休息时的表达方式。偏好在生成时作为独立提示注入，不覆盖原卡，不改变权威计时和权限；实际模型是否遵循需用用户的真实接口验收。角色卡和陪伴偏好有各自的保存按钮。

开场白可以留空、预览去除 HTML 后的文本，再自行选择“采用纯文本开场”并保存，供酒馆使用；桌宠不使用该开场。编辑开场字段不重写已有聊天；“新开聊天”先归档旧记录，再从空白开始，等待用户输入。休息主动回复由学习状态触发。正在学习、暂停或休息时可编辑表单，结束整个任务后再保存/切换。

角色书可在页面展开查看内嵌及关联世界书条目，并逐条删除；“酒馆高级编辑”启用所选角色并打开真正的酒馆窗口，处理角色书、复杂提示词与扩展。修改完点击“重新读取”同步。离开角色管理或切换编辑对象时，未保存草稿会提示确认；隐藏到小窗保留当前表单。验证命令为 `node scripts/workshop-integration.mjs`，加 `--packaged` 检查成品；均使用隔离数据和本机模拟模型。

### 更换角色（0.2.1）

在“学习中心 → 陪伴设置 → 角色卡”中点击“导入 PNG/JSON 角色卡”，或刷新“酒馆中已有角色”列表，选中后点击“使用此角色”。PNG 必须含内嵌角色数据，优先读取 V3；支持 V2/V3 JSON 和含名称的旧版 JSON。同名卡会建立不同的酒馆角色文件，不覆盖已有角色。导入只加入本机酒馆，点击“使用此角色”才会切换；不需要重新打包。

切换前请结束当前学习任务。当前自由聊天先保存到学习记录，切回已有角色会恢复该角色的当前聊天；重启后继续使用所选角色。保存失败时保留原角色与聊天。历史消息按原角色标注。若所选角色在酒馆中被删除，设置会提示重新选择；不会默默改用另一张卡。桌面狐狸素材不随角色卡变更。

角色库保存在本机用户数据目录的 `tavern-data/default-user/characters/`，选择与会话引用记录在 `chat-library.json`。未附带默认角色卡也能进入设置导入角色。开发版与成品的中性测试命令分别为 `node scripts/characters-integration.mjs` 和 `node scripts/characters-integration.mjs --packaged`；使用隔离数据和本机模拟接口，不调用真实模型服务。

聊天窗口的 ⚙ 设置按钮切换大小窗，进入大界面的“陪伴设置”。选择对话 API 供应商、填写地址及密钥后获取模型列表；MiMo 语音单独配置，可选茉莉、冰糖等预置音色。留空密钥保留原值，使用“清除已保存密钥”后保存可删除。地址改变后需显式填写或清除密钥。对话默认模型 `deepseek-flash`，可填写账户实际支持的模型。设置 TTS 开关不会启用系统语音。

0.2.0 按“任务 → 学习段 → 聊天”组织记录。结束本段时先保存再清空小窗，休息聊天继续归入该段；开始下一段时使用新会话。结束任务后小窗清空，学习时间归零。大界面可按主题/日期查找任务、查看所有段，并在所选段内查找聊天文字；历史为只读查询，不会改变当前会话。升级前聊天按原文件保留，不猜测旧的分段边界。详见 [任务归档与大界面](docs/task-archive.md)。

右上角图钉切换聊天置顶，重启后保留选择。双方已保存消息下方均有“编辑”“删除”，删除只影响一条；最新角色回复另有“重新生成”。修改直接保存到酒馆并用于后续上下文，生成期间不可修改记录。重新生成不新增用户消息、不重复计算学习交流轮数；失败、取消或服务中断时保留原回复。重启时恢复中断前的回复。操作说明和测试见 [聊天操作记录](docs/chat-controls.md)。

0.1.5 修复旧学习状态通知在回复后被移到聊天底部的问题，通知保留在原对话位置并显示发生时间。聊天两轮或 30 轮都不会自动结束学习，30 轮仅提醒一次。

按钮或完整指令 `开始学习`、`暂停学习`、`继续学习`、`结束学习`、`结束任务` 控制状态。`结束学习` 结束本段并进入休息，会主动开场一次；下一段由用户开始。含糊的聊天内容不改变状态。学习每完成 30 轮交流提醒一次。系统睡眠暂停计时，唤醒自动继续；用户手动暂停保持暂停，锁屏不暂停。

正文流式显示；完整回复后提取引号中的台词播报，动作和旁白保留在文字中。无法确定为台词的文字保持静默。狐狸有待机眨眼、拖动、等待、休息呼吸和播放中的轻微动作；现有素材缺少嘴型动画，未实现逐字口型。

关闭聊天小窗会收起到托盘，不退出程序。托盘可重新打开聊天、显示狐狸或退出。“打开角色与世界书设置”显示实际酒馆前端，可调整世界书和生成预设；当前原型绑定已导入角色，不承诺任意第三方扩展兼容。

## 前台应用与窗口标题（0.1.1）

点击“开始学习”后，展开学习卡片下方的“窗口观察”。每秒通过本机 Win32 接口读取前台窗口的应用名称、进程名、PID、完整窗口标题和程序路径；无需 API 密钥。这个版本只展示读取结果，尚未根据应用或标题自动分类、提醒或截图。

切换到 Edge 等应用后，等约一秒再点击狐狸回来查看。由于这时前台已是桌宠，面板明确显示“最近外部窗口”及读取时间，保留刚才外部应用的标题。若 Edge 窗口标题包含 B 站视频名，可直接读到那段文本；尚未在 B 站实际播放场景验证，全屏、画中画、分屏时的标题可能不同。不读取其他标签页、网址、页面正文或播放状态。

默认仅学习期间启用；暂停、休息、任务结束、系统睡眠或锁屏会停止读取并清空结果，继续学习或解锁后按当前学习状态恢复。设置中可关闭“学习时读取前台应用与窗口标题”。权限不足时可能只有标题和 PID，程序路径显示为不可用；无法获取前台窗口时显示未知，不沿用旧窗口作为当前观察。

这些数据只在内存和本机界面中使用，不写入聊天或学习快照，不发送给模型，也不会触发截图、摄像头或娱乐提醒。窗口标题本身不能证明视频正在播放或用户正在观看。组件使用 Windows 自带的 .NET Framework 4.x 运行环境；不需要另装 PowerShell 7 或开发工具来使用成品。

## P1 修复（0.1.2）

- 学习切换与休息开场使用段号和状态版本校验；重复结束不会重复开场。切换学习状态会取消未完成的旧回复，保留已显示的部分文字。
- “停止播报”清空待播并使在途回复的后续语音失效，文字仍可继续；“停止回复”取消生成，不计完整交流轮数，也不再合成语音。后续新消息仍能正常播报。
- 保存设置与生成共用操作准入，设置写入本身串行合并；重新配置保留本机通知。保存设置期间不能发送新消息，草稿不会因此清空。
- 酒馆启动、探测、角色导入、配置与生成有截止时间。无法正常取消的运行实例会被关闭，防止后台生产者和新请求重叠；服务异常后可点击“重启对话”，无需重启学习任务。
- 保存失败会显示未保存状态并重试最新快照；同一临时文件始终只有一个写入者。睡眠事件立即请求保存。退出时保存失败或设置提交未完成，会取消本次退出；可重试保存，或明确选择“仍然退出”并接受未保存数据丢失。

详细编号、测试和计划项边界见 [P1 修复记录](docs/p1-fixes/report.md)。此前三张评审图与清单保留为修复前的代码快照。

## 当前范围与验证

这是用于验证角色对话与桌宠表现的首轮原型。本机使用用户提供的 V3 JSON 角色卡、8 条世界书和狐狸 PNG 验证；公开仓库不附带角色卡或世界书内容。摄像头、多屏观察、行为提醒的 5/10/15 分钟规则、Telegram、资料库和长期记忆尚未实现，详细范围见 [设计记录](docs/product-design.md)。

`docs/integration-report.json` 与 `docs/packaged-integration-report.json` 记录真实酒馆配合本机模拟模型/TTS 服务的集成检查。窗口读取使用实际 Edge 与独立本机测试页面，验证进程路径、中文和特殊字符标题、标题变化、最近外部窗口、关闭/暂停/锁屏清理及数据未注入对话或持久化。锁屏与睡眠事件通过模拟事件验证，未进行实际锁屏硬件测试。**没有使用真实 DeepSeek/MiMo 密钥；真实人设表现、合成音色与摄像头效果尚未验证。** 不将测试固定回复作为 AI 实际能力。单元测试覆盖计时、休眠恢复、30 轮额度、明确指令边界和窗口采样校验。

## 本机数据

- 数据位于 `%APPDATA%/friend-desktop/`；测试使用工作区 `.test-data/`，互不混用。
- `settings.json` 中的两种 API 密钥通过 Electron `safeStorage` 使用 Windows 加密保存；界面查询不返回密钥。
- SillyTavern 仅保存每次运行随机生成的本机转发令牌，不保存真实服务密钥。真实请求由 Electron 主进程向用户配置地址发送。
- `tavern-data/` 保存角色、世界书和酒馆聊天；`session.json` 保存学习计时快照，退出前保存，运行中每 15 秒保存。重新启动时，原学习状态恢复为暂停，避免将关闭期间计为学习。
- `chat-library.json` 保存任务、学习段、会话文件引用及休息时隐藏的消息标识，不复制模型密钥。聊天正文仍来自原酒馆 JSONL。仅在归档保存成功后清空界面；保存失败暂停并保留原聊天，可重试。
- 学习期间按设置读取前台应用及窗口标题；不采集屏幕或摄像头，不上传文件。窗口读取结果不发送给模型；用户发送的文字和角色上下文会交给所配置的对话服务，提取的台词交给配置的语音服务。
- 原型备份可在退出后复制整个数据目录。加密密钥依赖当前 Windows 用户，迁移后需重新配置。

## 开发

需要 Node.js 24、npm 和 Git，使用 PowerShell 7：

```powershell
npm ci
npm run setup
```

启动后可在陪伴设置中导入自己的 PNG/JSON 角色卡。也可将默认 V3 JSON 放到 `assets/characters/主人的猫.json`（兼容路径，目录与文件自行创建），仅首次尚未选择角色时使用；已选择角色以后优先恢复本机酒馆中的角色。该目录已被 Git 忽略，请勿使用 `git add -f` 强行提交私人素材。

```powershell
npm start
```

`setup` 获取固定的 SillyTavern 版本并安装其锁文件依赖，下载官方 Node 24.14.0 Windows x64 运行包并验证 SHA256。应用运行使用此内置 Node，不依赖系统 Node。工程使用 TypeScript 和 Electron 41。构建窗口读取组件使用 Windows .NET Framework 自带的 x64 `csc.exe`，原始源码位于 `native/ForegroundReader.cs`，编译产物一并打包。

```powershell
npm run typecheck
npm test

```

集成测试需要安装 Edge、准备本地角色卡，并完成运行依赖安装，会创建独立测试浏览器并短暂切换测试窗口焦点。部分旧集成断言针对原测试卡的 8 条世界书，换卡后需相应调整；单元测试不依赖私人角色卡。`tests/FocusTestWindow.cs` 仅用于聚焦测试创建的窗口，不包含在成品中，不控制用户已有标签页。

`npm run package` 会把本机角色卡放进构建产物，发布安装包前必须另外检查私人素材。导出纯源码请使用 `pwsh.exe -NoLogo -NoProfile -NonInteractive -File scripts/export-source.ps1`：只导出 Git 的已提交 `HEAD`，不会把工作区未提交的角色卡、密钥或测试数据打包。

构建输出目录为 `release/0.5.2/win-unpacked`。GitHub 的 0.5.2 仅提供源码，不上传本机免安装目录、角色卡或密钥。当前目录构建尚未签名或提供安装器，公开发布二进制前需要补全发布测试和素材授权记录。
