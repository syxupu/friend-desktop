# Friend 学习桌宠

Windows 10 / 11 x64 的本机桌宠原型。点击狐狸打开聊天，拖动狐狸移动位置。对话由随软件运行的 **SillyTavern 1.19.0** 处理角色卡、世界书和上下文，DeepSeek 提供生成，MiMo 提供语音。

**公开源码版本为 0.2.0，不包含角色卡、API 密钥、聊天记录、个人运行数据或已有安装包。** 使用前请自行准备角色卡和配置自己的密钥，见下方“开发”。现有本机打包目录含私人角色卡，不作为公开发行包上传。文档中提到的本机验证 JSON、截图及评审页面未纳入公开仓库。

在另一台电脑继续开发，请先阅读 [开发交接](docs/HANDOFF.md) 和根目录 [AGENTS.md](AGENTS.md)，其中包含环境准备、实现边界、已确认规则、代码导航、验证限制及待办建议。

## 运行

打开 `release/0.2.0/win-unpacked/Friend 桌宠.exe`。保留整个 `win-unpacked` 文件夹，不能只复制 exe。程序包含 Node 和酒馆运行依赖，首次启动需要编译酒馆前端，请稍候。旧版输出保留在原目录，新旧版本不要同时运行。

右上角“学习中心”在聊天小窗和大界面之间切换，设置按钮直接进入大界面的“陪伴设置”。分别填写 DeepSeek 和 MiMo 的 API 地址、模型及密钥；MiMo 可选茉莉、冰糖等预置音色。留空密钥保留原值，使用“清除已保存密钥”后保存可删除。对话默认模型 `deepseek-flash`，可填写账户实际支持的模型。设置 TTS 开关不会启用系统语音。

0.2.0 按“任务 → 学习段 → 聊天”组织记录。结束本段时先保存再清空小窗，休息聊天继续归入该段；开始下一段时使用新会话。结束任务后小窗清空，学习时间归零。大界面可按主题/日期查找任务、查看所有段，并在所选段内查找聊天文字；历史为只读查询，不会改变当前会话。升级前聊天按原文件保留，不猜测旧的分段边界。详见 [任务归档与大界面](docs/task-archive.md)。

右上角图钉切换聊天置顶，重启后保留选择。双方已保存消息下方均有“编辑”“删除”，删除只影响一条；最新角色回复另有“重新生成”。修改直接保存到酒馆并用于后续上下文，生成期间不可修改记录。重新生成不新增用户消息、不重复计算学习交流轮数；失败、取消或服务中断时保留原回复。重启时恢复中断前的回复。操作说明和测试见 [聊天操作记录](docs/chat-controls.md)。

0.1.5 修复旧学习状态通知在回复后被移到聊天底部的问题，通知保留在原对话位置并显示发生时间。聊天两轮或 30 轮都不会自动结束学习，30 轮仅提醒一次。

按钮或完整指令 `开始学习`、`暂停学习`、`继续学习`、`结束学习`、`结束任务` 控制状态。`结束学习` 结束本段并进入休息，会主动开场一次；下一段由用户开始。含糊的聊天内容不改变状态。学习每完成 30 轮交流提醒一次。系统睡眠暂停计时，唤醒自动继续；用户手动暂停保持暂停，锁屏不暂停。

正文流式显示；完整回复后提取引号中的台词播报，动作和旁白保留在文字中。无法确定为台词的文字保持静默。狐狸有待机眨眼、拖动、等待、休息呼吸和播放中的轻微动作；现有素材缺少嘴型动画，未实现逐字口型。

关闭聊天小窗会收起到托盘，不退出程序。托盘可重新打开聊天、显示狐狸或退出。“打开角色与世界书设置”显示实际酒馆前端，可调整世界书和生成预设；当前原型绑定已导入角色，不承诺任意第三方扩展兼容。

## 前台应用与窗口标题（0.1.1）

点击“开始学习”后，展开学习卡片下方的“窗口观察”。每秒通过本机 Win32 接口读取前台窗口的应用名称、进程名、PID、完整窗口标题和程序路径；无需 API 密钥。这个版本只展示读取结果，尚未根据应用或标题自动分类、提醒或截图。

切换到 Edge 等应用后，等约一秒再点击狐狸回来查看。由于这时前台已是桌宠，面板明确显示“最近外部窗口”及读取时间，保留刚才外部应用的标题。若 Edge 窗口标题包含 B 站视频名，可直接读到那段文本；尚未在 B 站实际播放场景验证，全屏、画中画、分屏时的标题可能不同。不读取其他标签页、网址、页面正文或播放状态。

默认仅学习期间启用；暂停、休息、任务结束、系统睡眠或锁屏会停止读取并清空结果，继续学习或解锁后按当前学习状态恢复。设置中可关闭“学习时读取前台应用与窗口标题”。权限不足时可能只有标题和 PID，程序路径显示为不可用；无法获取前台窗口时显示未知，不沿用旧窗口作为当前观察。

这些数据只在内存和本机界面中使用，不写入聊天或学习快照，不发送给模型，也不会触发截图、摄像头或娱乐提醒。窗口标题本身不能证明视频正在播放或用户正在观看。组件使用 Windows 自带的 .NET Framework 4.x 运行环境；不需要另装 PowerShell 7 或开发工具来使用成品。

## P1 修复（0.1.2）

- 学习切换与休息开场使用段号和状态版本校验；重复结束不会重复开场。切换学习状态会取消未完成的旧回复，保留已显示的部分文字。
- “停止播报”清空待播并使在途回复的后续语音失效，文字仍可继续；“停止回复”取消生成，不计完整交流轮数，也不再合成语音。后续新消息仍能正常播报。
- 保存设置与生成共用操作准入，设置写入本身串行合并；重新配置保留本机通知。保存设置期间不能发送新消息，草稿不会因此清空。
- 酒馆启动、探测、角色导入、配置与生成有截止时间。无法正常取消的运行实例会被关闭，防止后台生产者和新请求重叠；服务异常后可点击“重启对话”，无需重启学习任务。
- 保存失败会显示未保存状态并重试最新快照；同一临时文件始终只有一个写入者。睡眠事件立即请求保存。退出时保存失败或设置提交未完成，会取消本次退出；可重试保存，或明确选择“仍然退出”并接受未保存数据丢失。

详细编号、测试和计划项边界见 [P1 修复记录](docs/p1-fixes/report.md)。此前三张评审图与清单保留为修复前的代码快照。

## 当前范围与验证

这是用于验证角色对话与桌宠表现的首轮原型。本机使用用户提供的 V3 JSON 角色卡、8 条世界书和狐狸 PNG 验证；公开仓库不附带角色卡或世界书内容。摄像头、多屏观察、行为提醒的 5/10/15 分钟规则、Telegram、资料库和长期记忆尚未实现，详细范围见 [设计记录](docs/product-design.md)。

`docs/integration-report.json` 与 `docs/packaged-integration-report.json` 记录真实酒馆配合本机模拟模型/TTS 服务的集成检查。窗口读取使用实际 Edge 与独立本机测试页面，验证进程路径、中文和特殊字符标题、标题变化、最近外部窗口、关闭/暂停/锁屏清理及数据未注入对话或持久化。锁屏与睡眠事件通过模拟事件验证，未进行实际锁屏硬件测试。**没有使用真实 DeepSeek/MiMo 密钥；真实人设表现、合成音色与摄像头效果尚未验证。** 不将测试固定回复作为 AI 实际能力。单元测试覆盖计时、休眠恢复、30 轮额度、明确指令边界和窗口采样校验。

## 本机数据

- 数据位于 `%APPDATA%/friend-desktop/`；测试使用工作区 `.test-data/`，互不混用。
- `settings.json` 中的两种 API 密钥通过 Electron `safeStorage` 使用 Windows 加密保存；界面查询不返回密钥。
- SillyTavern 仅保存每次运行随机生成的本机转发令牌，不保存真实服务密钥。真实请求由 Electron 主进程向用户配置地址发送。
- `tavern-data/` 保存角色、世界书和酒馆聊天；`session.json` 保存学习计时快照，退出前保存，运行中每 15 秒保存。重新启动时，原学习状态恢复为暂停，避免将关闭期间计为学习。
- `chat-library.json` 保存任务、学习段、会话文件引用及休息时隐藏的消息标识，不复制模型密钥。聊天正文仍来自原酒馆 JSONL。仅在归档保存成功后清空界面；保存失败暂停并保留原聊天，可重试。
- 学习期间按设置读取前台应用及窗口标题；不采集屏幕或摄像头，不上传文件。窗口读取结果不发送给模型；用户发送的文字和角色上下文会交给所配置的对话服务，提取的台词交给配置的语音服务。
- 原型备份可在退出后复制整个数据目录。加密密钥依赖当前 Windows 用户，迁移后需重新配置。

## 开发

需要 Node.js 24、npm 和 Git，使用 PowerShell 7：

```powershell
npm ci
npm run setup
```

启动前，将**自己的 SillyTavern V3 JSON 角色卡**放到 `assets/characters/主人的猫.json`（目录与文件需自行创建）。这是当前版本保留的兼容文件名，卡内角色名与设定可自行选择，不要求使用某个指定角色。卡需包含标准 V3 字段（包括 `data.name`），可包含自己的世界书。PNG 角色卡请先用可信工具导出 V3 JSON。该目录已被 Git 忽略，请勿使用 `git add -f` 强行提交私人素材。缺少此文件时对话服务无法完成角色导入。

```powershell
npm start
```

`setup` 获取固定的 SillyTavern 版本并安装其锁文件依赖，下载官方 Node 24.14.0 Windows x64 运行包并验证 SHA256。应用运行使用此内置 Node，不依赖系统 Node。工程使用 TypeScript 和 Electron 41。构建窗口读取组件使用 Windows .NET Framework 自带的 x64 `csc.exe`，原始源码位于 `native/ForegroundReader.cs`，编译产物一并打包。

```powershell
npm run typecheck
npm test
npm run test:integration
npm run package
```

集成测试需要安装 Edge、准备本地角色卡，并完成运行依赖安装，会创建独立测试浏览器并短暂切换测试窗口焦点。部分旧集成断言针对原测试卡的 8 条世界书，换卡后需相应调整；单元测试不依赖私人角色卡。`tests/FocusTestWindow.cs` 仅用于聚焦测试创建的窗口，不包含在成品中，不控制用户已有标签页。

`npm run package` 会把本机角色卡放进构建产物，发布安装包前必须另外检查私人素材。导出纯源码请使用 `pwsh.exe -NoLogo -NoProfile -NonInteractive -File scripts/export-source.ps1`：只导出 Git 的已提交 `HEAD`，不会把工作区未提交的角色卡、密钥或测试数据打包。

构建输出目录为 `release/0.2.0/win-unpacked`。当前提供免安装目录构建，在 Windows 10 x64 本机验证，尚未签名、提供安装器或验证 Windows 11；首次公开发布前需要补全发布测试和素材授权记录。
