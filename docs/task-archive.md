# 任务归档与大界面（0.2.0）

已确认：每次“结束本段”都归档并清空聊天小窗；“结束任务”同样清空，并使本段计时归零。休息聊天归入刚结束的段。大界面用于设置和查询，以任务为一级、任务下的学习段为二级。

## 使用

- 标题栏“学习中心”进入大界面，“小窗”或左下“返回聊天小窗”恢复原尺寸。点击狐狸仍打开聊天小窗。托盘也提供学习中心入口。
- 开始学习创建任务及第一段；休息后“开始下一段”仍属于同一任务。“结束任务”结束整个任务，下一次开始建立新任务。
- 每段使用独立的酒馆会话。小窗只显示当前段的聊天；进入休息时隐藏已结束的学习聊天，新产生的休息聊天继续保存到同一段，沿用该段上下文。下一段是新会话，角色及世界书保留；跨段长期摘要尚未实现。
- 结束任务后创建空的待开始会话，时间为 `00:00:00`，旧任务记录仍可在大界面查询。任务外自由聊天在下次开始学习时独立归档。
- 任务列表支持学习主题、日期筛选；点开任务可查看各段时长与聊天，再按文字查找当前段。历史面板只读，不切换正在使用的酒馆会话。当前小窗仍支持编辑、单条删除和重新生成最新回复。
- 设置复用原有密钥加密存储和留空保留规则；切换界面不暂停计时、不停止当前回复。

## 保存与恢复

`src/archive.ts` 的 `ConversationArchive` 将元数据保存到用户数据目录的 `chat-library.json`。正文保留在 `tavern-data/default-user/chats/<角色>/<会话>.jsonl`，查询仅通过已登记的任务/段 ID 获取引用，不接受任意读取路径。

结束操作先暂停计时、取消在途生成并等待它退出，再通过酒馆确认当前聊天已保存，随后提交归档索引。只有提交成功后才清空小窗。磁盘失败时保持暂停，原聊天仍显示，可重新结束；不把清空界面当作删除原文件。索引写入排队并原子替换。旧段号或旧状态阶段的异步更新不能覆盖新段/已结束阶段。

切换会话前先持久化目标引用及计划状态。若切换失败或应用中断，重启对话服务/软件会按该引用恢复；保存的学习状态在应用重启后恢复为暂停，休息保持休息，结束任务保持零计时。休息阶段隐藏的学习消息标识也持久化，避免设置保存、回复刷新或重启再次显示它们。

第一次升级扫描当前角色的已有聊天，保留原文件字节，不虚构旧的分段。旧记录标注为升级前记录，收录时间为升级时间。仍在进行的学习段保留原段号，新段继续递增。查询时若原酒馆文件被外部删除，会显示读取失败，索引保留。
