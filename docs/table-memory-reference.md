## 已观察到的机制

| 机制 | 静态阅读证据 | 对 Friend 的参考价值 |
| --- | --- | --- |
| 自定义表格模板 | `getTableTemplate()`、`importTemplate()`，支持全局与聊天作用域 | 使用学习专用字段，提供查看与纠错入口 |
| 表格增删改 | `insertRow()`、`updateRow()`、`deleteRow()`、`updateCell()` | 将摘要维护成可编辑记录 |
| 数据导入导出 | `exportTableAsJson()`、`importTableAsJson()` | 手动备份、恢复与迁移 |
| 保存与聊天关联 | 表格操作文档描述保存到聊天历史；源码读取 `TavernDB_ACU_Data` 与隔离标识 | 需要明确跨聊天、跨日期、跨角色的记忆范围 |
| 对话注入 | `syncWorldbookEntries()`、`refreshDataAndWorldbook()` | 把相关记忆提供给 SillyTavern 角色生成 |
| 纪要压缩 | `mergeSummaryNow()`；源码包含纪要与长期总结流程 | 减少重复内容与上下文体积 |
| 外部访问 | `window.AutoCardUpdaterAPI` | 若选择集成，可通过固定版本桥接验证接口 |

默认模板和提示词主要面向剧情记录。学习助手需要专门定义事实来源、学习进展与用户纠正，不能把默认剧情规则当成学习事实判定规则。

## 建议的学习专用表格（尚待设计确认）

| 表格 | 主要字段 |
| --- | --- |
| 学习段记录 | 段 ID、任务 ID、开始/结束时间、有效学习时长、主题、摘要、来源引用 |
| 知识与进展（跨角色共享） | 科目/主题、用户确认的进展、难点、下一步、更新时间、来源类型、确认状态 |
| 用户偏好 | 用户明确表达的偏好、适用范围、来源消息、更新时间 |
| 角色交流记忆（按角色隔离） | 角色 ID、交流摘要、约定、来源消息、确认状态 |

来源类型至少区分用户明确说明、有效观察、AI 推断与用户纠正。看见做题只支持描述行为；未读清题目时不生成具体知识掌握结论。角色的虚构经历不写入用户真实学习档案。

## 建议的更新与召回流程

1. 用户结束本段学习后，冻结该段有效记录并提交一次摘要任务。
2. 根据任务主题、有效观察与用户补充生成结构化摘要；后台摘要不计入聊天轮数、不作为角色台词播报。
3. 程序校验字段、来源和段 ID 后保存，重复响应不重复插入；生成失败时保留基础记录并标记摘要待生成。
4. 休息开场优先使用本段摘要；长期记忆按当前话题选择相关条目，避免把全部表格塞进每次对话。
5. 用户修改或删除后，同步更新后续召回与注入内容，避免再次召回被纠正或删除的内容。

建议由本机记忆模块维护规范记录，再经 SillyTavern 桥接提供对话所需内容。可参考插件的表格、纪要和世界书同步机制；直接内置整个插件仍需核实复用授权、宿主依赖、版本兼容和删除同步行为。

提醒次数、学习状态、手机豁免与计时由程序维护，摘要模型和角色提示词不直接修改这些状态。AI 输出作为经过校验的数据处理，不执行生成的任意代码或数据库命令。
